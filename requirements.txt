# OpenAlex Faculty Matcher

This is a single-file Streamlit Cloud version to avoid folder/import problems.

## Files required

```text
streamlit_app.py
requirements.txt
.streamlit/config.toml
```

## Streamlit Cloud setup

Main file path:

```text
streamlit_app.py
```

Secrets:

```toml
OPENALEX_API_KEY = "your_openalex_api_key_here"
```

## Important

`requirements.txt` must contain only package names.  
`streamlit_app.py` must contain Python code, not package names.
